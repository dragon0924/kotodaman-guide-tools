# データと画像の来歴

この公開用コピーは、元のGit履歴・記事・画像・キャラDBを取り込まずに準備しています。

| 対象 | 来歴 |
| --- | --- |
| `data/characters.json` | 新規作成した24件の架空キャラ。氏名・性能値・効果文は実ゲーム情報を示さない |
| 記事JSON | 新規作成した架空イベント1件、架空クエスト1件、非公開制御の検証専用下書き1件 |
| `content/public/` | 上記2件の架空公開記事だけ。検証下書きは含めない |
| `public/images/demo/` | 新規作成した文字・幾何学図形のPNG/WebP、8点。ゲーム画像・スクリーンショットのコピーではない |
| `docs/screenshots/` | 同梱の架空データを使ったローカル画面。ゲーム画像や秘密設定を含めない |
| 特性名等の短いラベル | 既存の検索コードを検証するための入力例。ゲーム内効果文の再配布ではない |
| テスト | 独立した小さなfixtureを使用。実DB・制作中記事に依存するassertionは非同梱 |

GameWithや公式サイト等のURLがparserやテストの形式例としてコードに現れる場合がありますが、ネットワーク取得やその成果物を同梱するものではありません。サンプル画像の実行時外部配信はありません。

このリポジトリを実ゲームDBの再配布へ転用する場合は、各データ・画像の権利と利用条件を別途確認してください。私有リポジトリや暗号化保存であっても、第三者素材の外部送信を無条件で許可するものではありません。
